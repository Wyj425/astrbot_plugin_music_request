# 大肥鱼点歌

适用 AstrBot **4.29.3 及以上**，Python 3.12；当前实际验证版本为 AstrBot 4.29.3。其他版本需自行验证兼容性。

- 支持 QQ音乐、网易云音乐、酷狗搜索，按歌名/歌手匹配；不明确时返回候选列表。
- 命令示例：`点歌 晴天`、`我要听周杰伦的晴天`、`网易云点歌 陈奕迅的十年`、`选歌 1`。
- 选歌列表按会话和发起用户隔离；遵守群聊回复规则中的仅@名单。
- 签名链接卡片依赖 QQ卡片签名；普通链接模式可不安装签名插件。
- 卡片打开原平台歌曲页面，不承诺绕过会员限制或 QQ 内直接播放。

## 安装

1. 本插件仓库：[Wyj425/astrbot_plugin_music_request](https://github.com/Wyj425/astrbot_plugin_music_request)，由 `Wyj425` 维护。
2. 在 AstrBot → 插件 → 从链接安装，填写 `https://github.com/Wyj425/astrbot_plugin_music_request`；也可导入只包含本目录的 ZIP。不要上传整个工作目录。
3. AstrBot 按 `requirements.txt` 安装 Python 依赖。启用插件后，在插件配置页设置。
4. 签名卡片模式依赖 astrbot_plugin_qq_card；不依赖社区精选或平台读取插件。

## 使用与登录

配置项、默认值和边界见 [配置说明](docs/CONFIGURATION.md)。首次安装请填写自己的 QQ 接入平台 ID（如有此项），以及在 AstrBot 中已创建的模型/Embedding 提供商 ID。已部署用户迁移时保留原配置，不用重新填写订阅和历史。

签名卡片依赖：[QQ卡片签名](https://github.com/Wyj425/astrbot_plugin_qq_card)。

## 数据、费用与卸载

插件数据保存在 AstrBot 的 `data/plugin_data/music_request/`，配置位于 `data/config/music_request_config.json`。扫码凭据不返回到模型、聊天或普通日志。平台搜索/详情缓存按公开内容共享，会话最近链接按完整会话标识隔离；重启清空内存缓存，候选库与发送记录等业务数据库仍持久化。

平台读取与签名本身不调用语言模型。正文、评论和配图进入聊天模型时会增加输入用量；社区评分、兴趣分析、人设短评及知识提取仍按各插件设置计费。没有无限抓取或无限评论翻页。

卸载插件不会自动清除平台账户的远程登录，也不应直接删除需要保留的数据。停用平台插件后，消费者会报告依赖不可用或跳过该平台。需要重新安装时恢复本插件目录及配置；平台失效需重新扫码。
