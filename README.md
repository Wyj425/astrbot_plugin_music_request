# 大肥鱼点歌

**对 QQ 机器人说“我要听周杰伦的晴天”，它就会帮你找歌，发来可点击的歌曲卡片或链接。**

支持 QQ音乐、网易云音乐和酷狗音乐，适用于私聊和群聊。歌名或版本不明确时，会给出候选列表供你选择。

<img src="logo.png" width="120" alt="大肥鱼点歌插件图标">

## 能做什么

- 按歌名、歌手搜索歌曲，也可以指定音乐平台。
- 找到明确匹配的歌曲后直接发送结果。
- 多个版本难以确定时，列出候选，通过「选歌 1」继续选择。
- 按会话和发起用户保存选歌列表，群友可以分别选自己的歌。
- 选择普通链接、签名链接卡片，或尝试原生音乐卡片。

适用于 **AstrBot 4.29.3 及以上、Python 3.12，QQ / OneBot 接入**。当前已验证 AstrBot 4.29.3。

## 安装与起步配置

1. 在 **AstrBot → 插件市场** 搜索「大肥鱼点歌」，点击安装。
2. 打开 **AstrBot → 机器人**，找到已连接的 QQ / OneBot 机器人，复制它的 **平台实例 ID**。
3. 打开 **插件 → 大肥鱼点歌 → 配置**，将该 ID 填入 `platform_id`。
4. 确认 `enabled` 已开启，根据需要开启群聊和私聊。
5. 选择下面的一种结果展示方式，保存配置。
6. 私聊机器人发送「我要听周杰伦的晴天」进行测试。

`platform_id` 填的是 AstrBot 中的机器人实例 ID，请与「机器人」页面中的值完全一致。

## 结果展示方式

| 模式 | 需要准备什么 | 效果 |
| --- | --- | --- |
| 普通链接 | 将 `card_mode` 设为「普通链接」 | 发歌曲页面链接，适合先验证搜歌 |
| 签名链接卡片 | 安装「QQ卡片签名」并填入 Token | 带标题、封面和歌曲页面链接的卡片，建议作为卡片起步方式 |
| 自动 | 安装并配置「QQ卡片签名」 | 先尝试原生音乐卡片，失败后尝试签名链接卡片 |

卡片配置方法见 [QQ卡片签名使用说明](https://github.com/Wyj425/astrbot_plugin_qq_card)。点歌所需 Python 依赖由 AstrBot 安装，正常使用时无需另建音乐搜索服务器。

### 方式一：让 Agent 帮你配置卡片（推荐）

```text
我已经从 AstrBot 插件市场安装了「大肥鱼点歌」（music_request）。
请阅读：
https://github.com/Wyj425/astrbot_plugin_music_request

检查已连接的 QQ / OneBot 机器人，将正确的平台实例 ID 填入本插件
的 platform_id，确认插件及需要的群聊、私聊开关已开启。
先用普通链接模式验证搜索配置。

我希望收到带封面的歌曲卡片。请检查是否已安装「QQ卡片签名」
（astrbot_plugin_qq_card），需要时从插件市场安装。
指导我在该插件后台填入自己的 Token，Token 不要发到聊天中。
将点歌的 card_mode 设为「签名链接卡片」。

请让我私聊机器人发送「我要听周杰伦的晴天」，核对实际收到的
卡片标题、封面和点击后的歌曲是否正确。
```

### 方式二：自己手动配置卡片

1. 在插件市场安装「QQ卡片签名」。
2. 在 [咸鱼 API 开放平台](https://apii.xianyuw.cn) 注册登录，取得个人 Token。
3. 将 Token 填入 **QQ卡片签名 → 配置 → `ark_signing_token`**，开启该插件并保存。
4. 将 **大肥鱼点歌 → 配置 → `card_mode`** 设为「签名链接卡片」，保存。
5. 发送下面的点歌示例，检查卡片和跳转。

这套方式通过插件市场和配置页完成，无需额外执行服务器部署命令。

## 怎么点歌

| 想做什么 | 可以发送 |
| --- | --- |
| 按歌名点歌 | `点歌 晴天` |
| 指定歌手 | `我要听周杰伦的晴天` |
| 使用 QQ音乐 | `QQ音乐点歌 晴天` |
| 使用网易云 | `网易云点歌 陈奕迅的十年` |
| 使用酷狗 | `酷狗点歌 晴天` |
| 从候选列表选择 | `选歌 1` |
| 更换候选版本 | `换一个版本` |

群聊中可以 @机器人再发送点歌请求。选歌列表默认保留 **5 分钟**，过期后重新点歌即可。

## 常用设置

| 设置 | 用途 | 默认值 |
| --- | --- | --- |
| `platform_id` | QQ机器人平台实例 ID，首次安装必须填写 | 留空 |
| `enable_groups` / `enable_private` | 群聊、私聊点歌开关 | 均开启 |
| `enable_qq` / `enable_163` / `enable_kugou` | 选择搜索平台 | 均开启 |
| `disabled_groups` | 不启用点歌的群号 | 空列表 |
| `card_mode` | 结果展示方式 | 自动 |
| `candidate_count` | 最多列出的候选数 | 5 |
| `selection_minutes` | 候选列表有效期 | 5 分钟 |
| `cooldown_seconds` | 同一用户连续点歌的最短间隔 | 3 秒 |

更多设置见 [配置说明](docs/CONFIGURATION.md)。

## 常见问题

**发了点歌请求没反应？**

检查 `platform_id` 是否与已连接的机器人一致，插件、群聊或私聊开关是否开启，以及当前群是否在停用列表中。如果你配置了「只在被 @ 时回复」的用户限制，请让对应用户真正 @机器人再点歌。

**搜不到或找错版本？**

补充歌手、完整歌名，或指定另一个平台重试。平台搜索接口变化、网络问题和歌曲下架都可能影响结果。

**卡片能否直接播放会员歌曲？**

卡片打开的是歌曲原平台页面，播放权限由你的音乐账号和原平台决定。QQ 内能否直接播放还取决于卡片类型与客户端。

## 数据与费用

- 插件数据：`data/plugin_data/music_request/music.db`，保存待选歌曲和近期点歌处理记录。
- 插件配置：`data/config/music_request_config.json`。

直接点歌指令的搜索、选歌和发卡片流程本身不调用语言模型；自然语言请求由聊天模型调用点歌工具时，仍会产生正常聊天模型用量。签名服务费用以服务方规则为准。

备份时保存配置和需要保留的插件数据。卸载后可自行删除这两项。
